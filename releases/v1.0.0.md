# DRelease Release v1.0.0

Upcoming in the next release.

This version includes:

- A zero-dependency Node.js 24 Action, reusable workflow, and local notes-preview command.
- Automatic commit notes based on the latest version tag's date.
- Configurable release settings and additional Markdown notes.

<br/>

# Release notes

- Read the caller's full checkout, generate commit notes, move the nightly tag to the selected commit,
  and create or update a GitHub prerelease. A reusable workflow handles checkout and concurrency; each
  caller controls its own schedule. The Action also supports offline notes mode and a working directory.
- Select the most recently created version tag, excluding the moving nightly tag. Annotated tags use
  their tagger date; lightweight tags use their commit date. Include reachable commits whose committer
  timestamps are strictly after that date, or the full reachable history when no eligible tags exist.
- Accept a custom tag pattern, explicit baseline tag, and ISO 8601 start and end dates. Dates use UTC
  unless a timezone is supplied; the end date is inclusive.
- Allow a custom nightly tag, release title, checkout ref, token, notes path, and extra Markdown supplied
  inline or from a file. Preserve manual text outside the generated notes markers and publish either
  the generated section or the entire notes file.
- Update existing releases while preserving their assets, or optionally delete and recreate them to
  match pygemc's nightly behavior. Nightly releases remain prereleases and are not marked as latest.
- Provide the selected baseline tag, resolved start date, target commit, notes path, and release URL as
  action outputs. The local `drelease` command generates Markdown without fetching or publishing.

## Tests

- Added an offline native Node test suite covering version-tag selection, annotated tag dates, moving-tag
  exclusion, detached checkouts, full-history fallback, and non-monotonic commit dates.
- Tested Action outputs and job summaries, CLI parsing, target refs, and shallow-checkout errors.
- Covered date overrides, custom tag patterns, manual notes preservation, marker validation, additional
  notes, whole-file release bodies, and empty commit ranges.
- Mocked GitHub API calls for tag and release creation, updates, recreation, URL encoding, and errors.
- Added `npm run check` and `npm test`, plus CI on Node.js 24 and an offline root Action smoke test.

<br/>

## Supported platforms

- GitHub-hosted Ubuntu runners with Git; the Action supplies its Node.js 24 runtime.
- Local notes previews on Linux or macOS with Node.js 24+, Git, and Bash; Windows through WSL.

<br/>

## Dependencies

- Node.js 24 or newer, using only core modules; no npm runtime dependencies or build step.
- Git and a full repository checkout; the reusable workflow uses `actions/checkout@v6`.
- A GitHub token with `contents: write` permission for release publication through the GitHub API.
